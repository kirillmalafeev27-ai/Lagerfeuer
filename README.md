# Костры до рассвета · Bis zum Morgengrauen

Ночь в лесу, четыре костра вокруг крошечной поляны и волки, которые боятся огня. Каждый верный
ответ на вопрос по немецкому — шаг героя или полено в костёр. Берёза вспыхивает сразу, дуб горит
вдвое дольше, но разгорается медленно. Продержись до рассвета.

Вопросы сочиняет ИИ по выбранным темам — движок вопросов и ИИ-механика перенесены из Morskoy:
уровень A1–C1, лексическая тема, до пяти грамматических тем, девять форматов заданий (целые
предложения, преобразования, исправление ошибки, мини-диалоги…), проверка ответа модели кодом.
Есть и свой набор слов с заданиями, написанными вручную («Wortschatz für Sascha und
Präpositionen»). Без ключа генерации вопросы берутся из встроенного банка. Подробно —
[`docs/GENERATION.md`](docs/GENERATION.md), деплой — [`DEPLOY.md`](DEPLOY.md).

Весь арт рисуется кодом при запуске — «масляная пастель на чёрной бумаге»; свет костров
«вытирает» тьму, а на рассвете картинка проявляется в цвете. Звуки синтезируются WebAudio.
Шрифты Rubik и Rubik Scribble подключены локально; в сеть игра ходит только к своему серверу —
за вопросами.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (API вопросов — там же; ключ — в .env.local)
npm run build      # проверка типов, игра в dist/, сервер в dist-server/
npm start          # боевой сервер: игра и API вопросов на http://localhost:3000
npm run preview    # собранная версия (с API вопросов)
```

## Проверки

```bash
npm test           # правила, генерация и проверка заданий, источник вопросов, темп (Vitest)
npm run lint
npm run sim -- --check --runs 2000       # симуляция ботами и цели баланса (раздел 14 плана)
npm run sim -- --check-gen --runs 2000   # то же для ночей с заданиями генератора
npm run sim -- --mode gen --tmed 12 --sigma 0.65 --p 0.7   # ученик на заданиях генератора
npm run test:e2e   # ночь в браузере ботом-игроком: пауза, обучение, итоги, следующий уровень
npm run test:quiz  # вопросы от ИИ в браузере: формат заданий, выбор тем, ожидание, помощь
npm run test:dark  # тест темноты: контрасты WCAG на двух размерах и двух качествах
```

`test:e2e`, `test:quiz` и `test:dark` используют установленный в системе Playwright с Chromium.
Скриншоты: `node tools/shots.mjs "level=3" shots/l3 390x844 1280x720`, ключевые моменты ночи:
`node tools/tour.mjs`, арт-лаборатория: `npm run dev` и `/lab.html?only=flames`.

## Вопросы

Кнопка «Вопросы» в меню — выбор тем, как в меню Morskoy: уровень, лексическая тема, темы (они
чередуются), слот Wortstellung (порядок слов на материале первой темы) и аудирование. Генерация
идёт на сервере игры через AI Tunnel (`AITUNNEL_API_KEY`), очереди по темам пополняются заранее,
первое задание ночь ждёт в интро. Инструкции для ИИ — в `server/generation/`, их тексты совпадают
с Morskoy дословно.

Сложность подстраивается под вопросы: темп ученика считается отдельно для банка и для заданий
генератора каждого уровня A1–C1, с поправкой на разброс времени ответа. Ночь с заданиями-
предложениями не длиннее 6 минут, костры в ней горят медленнее, а дров на старте меньше — чтобы
и проходилась, и дуб по-прежнему окупался. После двух поражений подряд на ночи — «сухой мох»:
угли тлеют в полтора раза дольше (после четырёх — вдвое). Как это подбиралось симуляцией — в
`DECISIONS.md`, раздел «Сложность с заданиями генератора».

| Действие                    | Касание / мышь                       | Клавиатура      |
| --------------------------- | ------------------------------------ | --------------- |
| Ответить                    | табличка варианта                    | 1–4             |
| Шаг                         | клетка поляны                        | стрелка         |
| Подбросить, повторно — «×2» | костёр                               | Shift + стрелка |
| Берёза / дуб                | половина поленницы или переключатель | B / E           |
| К поленнице                 | поленница                            | H               |
| Стоять                      | герой или «Стоять»                   | Пробел          |
| Пауза                       | ❚❚                                   | P, Esc          |

## Устройство

- `src/core` — чистые детерминированные правила (`reduce(state, action)`), боты, генератор уровней.
- `src/config` — все числа (`balance.ts`, `levels.ts`, `look.ts`) и все цвета (`palette.ts`).
- `src/shared/pastelKit.ts` — пастельный кит: мазки, штриховка, зерно бумаги, кисти света.
- `src/shared/questions/` — источники вопросов (ИИ, банк), темы, озвучка аудирования;
  `src/shared/pace.ts` — учёт темпа, `src/game/pacing.ts` — темп по видам вопросов.
- `server/` — сервер вопросов: API, клиент AI Tunnel, озвучка; `server/generation/` — инструкции
  для ИИ и проверка ответа модели (из Morskoy); `server/vocab/` — свои наборы слов.
- `src/art` — рецепты текстур; `src/render` и `src/scenes` — Phaser 4; `src/ui` — DOM-интерфейс.
- `DECISIONS.md` — где и почему реализация отступает от плана.
